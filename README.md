# NeoGenea - Application de Généalogie

Application web de gestion d'arbres généalogiques, hébergée localement.

## Installation

```bash
npm install
```

## Configuration

1. Copier `.env.example` vers `.env`
2. Configurer vos identifiants MySQL dans `.env`
3. Créer la base de données MySQL (voir documentation)

## Démarrage

```bash
npm start
```

Le serveur démarre sur http://localhost:3007

## Documentation

Voir le répertoire `documentation/` pour plus de détails.
